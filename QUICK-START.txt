========================================
  JINVANI EBOOK READER - QUICK START
========================================

🚀 GETTING STARTED (3 Easy Steps):

1. ADD YOUR PDFs
   → Double-click: add-pdf.bat
   → Copy your PDF files to the opened folder
   → Organize into subfolders (optional)
   → Press any key to scan and update config

2. TEST LOCALLY
   → Double-click: open-local.bat
   → Your reader opens in browser
   → Check folder structure and PDFs

3. PUBLISH ONLINE
   → Double-click: push.bat
   → Enter commit message (or press Enter)
   → Wait 2-3 minutes
   → Double-click: open-github.bat

========================================
  BATCH FILES EXPLAINED
========================================

📁 add-pdf.bat
   - Opens media folder
   - Scans for PDFs and folders
   - Updates config.js automatically
   - Generates folder structure
   - USE THIS to add/organize books!

🚀 push.bat
   - Commits all changes
   - Pushes to GitHub
   - Publishes to live site
   - USE THIS after adding PDFs!

🌐 open-github.bat
   - Opens GitHub repository
   - Opens live website
   - USE THIS to view online!

💻 open-local.bat
   - Opens reader in browser
   - Tests before publishing
   - USE THIS to preview!

📥 pull.bat
   - Downloads latest changes
   - Syncs with GitHub
   - USE THIS to update!

📊 status.bat
   - Shows what changed
   - Checks Git status
   - USE THIS to check!

========================================
  TYPICAL WORKFLOW
========================================

ADDING NEW BOOKS:
1. add-pdf.bat (add PDFs)
2. open-local.bat (test)
3. push.bat (publish)
4. open-github.bat (view online)

UPDATING EXISTING:
1. Edit files
2. push.bat (publish changes)

SYNCING:
1. pull.bat (get latest)

========================================
  TROUBLESHOOTING
========================================

❌ PDFs not showing?
   → Run add-pdf.bat again
   → Check media/ folder has PDFs

❌ Can't push?
   → Check internet connection
   → Run status.bat to see errors

❌ Site not updating?
   → Wait 2-3 minutes
   → Clear browser cache (Ctrl+F5)
