# 📚 Complete Bookmark Guide

## Three Ways to Bookmark

### 1️⃣ Bookmark from Library (Bookmark Entire Book)
**When to use:** You want to save a book for later reading

**Steps:**
1. Browse books in the sidebar
2. Click on any folder to see PDFs
3. Find the book you want to bookmark
4. Click the **"Bookmark"** button on the PDF card
5. ✅ Book is saved to your bookmarks (at page 1)

**What happens:**
- Book is added to your bookmarks list
- You'll see a success notification
- You can access it later from "View Bookmarks"

---

### 2️⃣ Bookmark from PDF Viewer (Bookmark Current Page)
**When to use:** You're reading and want to save the current page

**Steps:**
1. Open any PDF book
2. Navigate to the page you want to bookmark
3. Click the **bookmark button (📑)** in the PDF control panel
4. ✅ Current page is bookmarked

**Alternative methods:**
- Click **"Add Bookmark"** button in the header (appears when PDF is open)
- Press **B** key on keyboard (quick shortcut)

**What happens:**
- Current page number is saved
- Button turns green with checkmark ✓
- Notification shows "Bookmark added: Page X"

---

### 3️⃣ View All Bookmarks
**Steps:**
1. Click **"View Bookmarks"** button in the header (near Home button)
2. Bookmarks display at bottom of home page
3. See all your saved books and pages

**What you'll see:**
- 📖 Book name
- 📄 Page number (if bookmarked from viewer)
- 📅 Date saved
- 🔘 "Open at Page X" button
- 🗑️ "Remove" button

## Troubleshooting

**Q: Bookmark button doesn't work?**
- Make sure you have a PDF open
- Check if browser allows localStorage
- Try refreshing the page

**Q: Can't see "Add Bookmark" in header?**
- This button only appears when a PDF is open
- Close and reopen the PDF if needed

**Q: Bookmarks disappeared?**
- Bookmarks are stored in browser localStorage
- Clearing browser data will remove bookmarks
- Use same browser/device to access bookmarks
