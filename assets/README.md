# Assets Folder

This folder contains images and other assets for the Jinvani eBook Reader.

## Required Image

**File:** `jain-statue.png` or `jain-statue.jpg`

**Description:** Jain Tirthankara statue image for branding

**Usage:**
- Header logo (40px width)
- Welcome screen (200px max-width)

**Instructions:**
1. Save your Jain Tirthankara statue image in this folder
2. Name it: `jain-statue.png` (or `.jpg`)
3. Recommended size: 400x800px or similar aspect ratio
4. Format: PNG with transparent background (preferred) or JPG

## Image Specifications

- **Format:** PNG (preferred) or JPG
- **Recommended Size:** 400-600px width
- **Aspect Ratio:** Portrait (statue should be vertical)
- **Background:** Transparent (PNG) or white (JPG)
- **File Size:** Keep under 500KB for fast loading

## Current Setup

The image is used in two places:
1. **Header Logo** - Small version (40px) with gentle floating animation
2. **Welcome Screen** - Larger version (200px) with floating and rotation animation

## Animations

- **Header:** Gentle up/down float (3s cycle)
- **Welcome Screen:** Float with slight rotation (4s cycle)
- **Hover Effect:** Scale up with enhanced shadow

## Fallback

If the image is not found, the page will show a broken image icon. Make sure to add your image file to this folder.
